# APEX Skills

[![Docs](https://img.shields.io/badge/docs-GitHub%20Pages-blue)](https://aws-samples.github.io/sample-apex-skills/) [![License: MIT-0](https://img.shields.io/badge/license-MIT--0-green)](../../LICENSE)

28 agent skills for AWS platform engineering on Amazon EKS and Amazon ECS: design, build, review, upgrade, secure and modernize. They follow the [Agent Skills standard](https://agentskills.io/) and run in Claude Code, Kiro CLI, Codex and other harnesses. Type `/apex` with your request and the router picks the right skill.

```bash
npx apex-skills@1.3.0
```

Needs Node.js 18+ and git. Every install option, the full skill catalog and the hands-on examples live on the docs site:

- [Getting started](https://aws-samples.github.io/sample-apex-skills/docs/getting-started)
- [Skill catalog](https://aws-samples.github.io/sample-apex-skills/docs/skills/)
- [Examples](https://aws-samples.github.io/sample-apex-skills/docs/examples/)

5 skills are vendored from upstream projects under their own licenses: see [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md). To contribute, see [CONTRIBUTING.md](../../CONTRIBUTING.md).

Sample code for educational and demonstration purposes only; test generated infrastructure in non-production environments first.
